# Bitrix24 LinkedIn Carousel

Use this skill when the user wants a Bitrix24 Partners carousel, banner series, or LinkedIn slide post in the visual language from the partner materials.

## Outcome

Produce a cohesive multi-slide social set that feels like one campaign, not unrelated banners. Match the Bitrix24 Partners brand style and the observed Figma composition patterns.

## Working Rules

- Default to a 5-7 slide sequence unless the user asks for a different count.
- Treat each slide as one message with one dominant takeaway.
- Keep the series modular: cover, middle content slides, and closing CTA should feel like variations of one system.
- Prefer short, sales-friendly copy with clear hierarchy. Headlines should be scannable in a feed.
- Keep composition visually calm: avoid stacking multiple hero objects unless the user explicitly asks for it.
- On cover slides, prefer exactly one main 3D object when using the 3D-icon direction.
- Do not let decorative or 3D elements overlap each other.
- Do not pin the text block to the bottom edge; keep the main text mass visually centered within the slide.
- Reuse the Bitrix24 Partners assets and design language from the local repository at `/Users/ksivancheva/Downloads/Скрины/bitrix24-partner-style`.
- When authoring or updating actual deliverables, read `/Users/ksivancheva/Downloads/Скрины/bitrix24-partner-style/assets/DESIGN_SYSTEM.md` and `/Users/ksivancheva/Downloads/Скрины/bitrix24-partner-style/assets/bitrix24-template.html`.
- For the specific LinkedIn banner/carousel pattern studied in Figma, read [references/linkedin-carousel-pattern.md](references/linkedin-carousel-pattern.md).

## Format Boundary

- Use this skill for LinkedIn carousel-style post series and landscape social banners in the Bitrix24 Partners style.
- Do not use this skill for generic web banners, non-Bitrix24 brands, or document-style PDFs.
- If the user asks for Instagram Stories, square carousels, or A4 brochures, keep the same brand voice but adapt the format instead of forcing this exact layout pattern.
