# Как пользоваться: Bitrix24 Partner Style (скилл для Claude Code)

Это гайд для команды: как поставить и как пользоваться **партнёрским фирменным стилем**
Bitrix24 внутри Claude Code. Скилл называется **`bitrix24-partner-style`** и собирает готовый
контент в фирстиле партнёрки — по одному запросу.

> Это **партнёрский** фирстиль. Другие фирстили Bitrix24 (например, корпоративный) — отдельные
> скиллы, чтобы не путались.

---

## Что он умеет

| Формат | Что это | Результат |
|---|---|---|
| **A4 книжный** | гайды, брошюры, one-pager'ы, плейбуки | PDF |
| **A4 альбомный** | широкие раздатки, «слайды» | PDF |
| **LinkedIn** | квадратные карусели/галереи 1080×1080 | PNG на каждый слайд |
| **Instagram Stories** | сторис 1080×1920 (с safe-зоной) | PNG на каждый слайд |

Внутри всё фирменное: шрифт **Montserrat**, официальные логотипы, **фирменный градиент-свечение**,
цвета, готовые компоненты (обложки, таблицы, карточки, сравнения, кнопка «Стать партнёром»),
а также библиотека **фото людей** и **иконок**. Ничего вручную оформлять не нужно.

---

## Установка (один раз)

**Что нужно на компьютере:**
- **Google Chrome** (почти у всех уже есть) — используется для рендера.
- **Python 3** — на macOS уже стоит; на Windows поставьте с python.org и **поставьте галочку
  «Add python.exe to PATH»**.
- Для картинок в соцсети — один раз выполните: `pip install pymupdf`

**Поставить скилл** — распакуйте архив `bitrix24-partner-style-skill.zip` и положите папку:

**macOS / Linux**
```bash
cp -R bitrix24-partner-style ~/.claude/skills/
```
Проверка: `ls ~/.claude/skills/bitrix24-partner-style/SKILL.md`

**Windows**
- Правый клик по архиву → «Извлечь всё», затем перетащите папку `bitrix24-partner-style` в
  `C:\Users\<вы>\.claude\skills\` (папки `.claude\skills` создайте, если их нет).
- Проверка (PowerShell): `dir "$env:USERPROFILE\.claude\skills\bitrix24-partner-style\SKILL.md"`

Перезапуск не нужен. Всё — скилл активен.

## Как пользоваться

Просто **опишите словами**, что нужно — скилл подхватится сам. Можно сослаться на фирстиль
явно («партнёрский фирстиль», «фирстиль партнёрки») или вызвать командой
`/bitrix24-partner-style`.

**Примеры запросов:**
- «Собери партнёрскую брошюру про Vibe+ на A4 в партнёрском фирстиле.»
- «Сделай карусель для LinkedIn на 5 слайдов: как продавать ценность, а не фичи.»
- «Нужна сторис в Инсту с CTA "Стать партнёром".»
- «Сделай альбомный A4 one-pager со сравнением тарифов.»
- «Оформи вот этот текст (вставляю ниже) как гайд для партнёров.»

Claude сам подберёт компоненты, сверстает и отрендерит финал (PDF или PNG). Готовый файл
появится рядом — Claude напишет путь.

**Совет по контенту:** дайте Claude сам текст/структуру (можно черновиком) — оформление он возьмёт
на себя. Чем конкретнее задача (формат, сколько страниц/слайдов, о чём), тем точнее результат.

## Что важно знать

- **Фирменный градиент.** Тёмные обложки/CTA идут на узнаваемом партнёрском градиенте-свечении
  (лазурь → тёмный navy) — это фирменная фишка, скилл её ставит сам.
- **Логотип** — только официальный локап (скилл использует правильные файлы, не собирает вручную).
- **Зелёный `#BDF300`** — только акцент/фон, не текст на белом (скилл соблюдает).
- **Фото и иконки** — есть библиотека: разнообразные люди-вырезки и брендовые иконки. Можно
  попросить «поставь на обложку человека посерьёзнее» или «замени эмодзи на брендовые иконки».
- **Соцсети — PNG на слайд.** Карусель из N слайдов = N картинок. Сторис учитывает safe-зону
  (контент не заедет под интерфейс Инсты).

## Если что-то не так

- **«Шрифт выглядит не как Montserrat»** — вы, скорее всего, открыли промежуточный HTML в браузере,
  где Montserrat не установлен. В итоговых **PDF/PNG шрифт зашит** правильно. Можно установить
  Montserrat в систему (бесплатный, Google Fonts), тогда и HTML-превью будет корректным.
- **Ошибка про Chrome** — установите Google Chrome.
- **Соцсети не экспортируются в PNG** — выполните `pip install pymupdf`.
- **Скилл не срабатывает** — проверьте путь установки (см. выше) и позовите его явно:
  `/bitrix24-partner-style`.
